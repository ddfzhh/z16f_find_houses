# z16f_find_houses

Source for an AI-powered house search: two friends looking for a cheap, big,
2–3 bedroom rental near Caltrain in Redwood City, San Carlos or Menlo Park.

**This repo is where the product is built, not where it's used.** Day to day,
people use the web app (a private claude.ai artifact) or their own Claude Code.

- [`SYSTEM.md`](SYSTEM.md): architecture and design decisions
- [`CLAUDE.md`](CLAUDE.md): how any AI agent works with the product
- [`PLAN.md`](PLAN.md): the human side (applications, tours, lease)
- `data/seed/`: initial listings and requirements to import
