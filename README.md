# z16f_find_houses

Planning and source for an AI-powered house search: two friends looking for a
cheap, big, 2–3 bedroom rental near Caltrain in Redwood City, San Carlos or
Menlo Park.

**This repo is where the product is built, not where it's used.** People will
use the web app or their own AI assistant.

- [`SPEC.md`](SPEC.md): what we're building (functions, data, scoring, workflow)
- [`CLAUDE.md`](CLAUDE.md): rules for any AI agent working on it
- [`PLAN.md`](PLAN.md): the human side (applications, tours, lease)
- `data/seed/`: initial listings and requirements text
